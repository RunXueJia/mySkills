# HyperFrames Modules

`hyperframes/SKILL.md` is the only discoverable entry point. Use this directory to load the smallest matching module for the task.

## Core Modules

- [hyperframes-cli](hyperframes-cli/MODULE.md) - init, lint, inspect, preview, render, doctor, browser, info, upgrade.
- [hyperframes-media](hyperframes-media/MODULE.md) - tts, transcribe, remove-background.
- [hyperframes-registry](hyperframes-registry/MODULE.md) - add, wire, discover registry blocks and components.
- [hyperframes-workflow](hyperframes-workflow/MODULE.md) - repeatable project flow, preview/render, Docker troubleshooting.

## Capture And Translation

- [website-to-hyperframes](website-to-hyperframes/MODULE.md) - capture a website and turn it into a video.
- [web-video-presentation](web-video-presentation/MODULE.md) - turn an article or script into a click-driven presentation.
- [remotion-to-hyperframes](remotion-to-hyperframes/MODULE.md) - translate Remotion compositions into HyperFrames HTML.
